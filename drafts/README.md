## Writing convention

Each skeleton has:
- **Hook** — the opening line/scene
- **The problem** — what the manual version looked like, with real numbers
- **What I built** — the actual solution, generalized (no internal tool names)
- **What broke** — real failure modes from the repos
- **What it still can't do** — honest limitations
- **The takeaway** — one sentence the reader carries away

Fill in your own voice between the markers. Don't change the structure until the first draft is done.
